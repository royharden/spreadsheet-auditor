# Deferred validation

This repository was built in Dirty Mode: source and tests were written and inspected, but nothing was installed, compiled,
linted, tested, built, generated, deployed or called. Every row below is a check that has **not** happened yet, with the step
that activates it. Rows are appended per milestone; none may be deleted until its activation step has actually passed.

From then on `npm ci`, then `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`. |
